# Queen SDA — Sistema de Automatización de Datos V2.0

Versión externa y **completamente gratuita** (código directo, sin constructores por créditos) del sistema del **restaurante-bar La Reina**. Es la réplica multiusuario en construcción del sistema original que vive en Muse; el sistema de Muse sigue siendo el oficial mientras esta versión no cuadre igual y el dueño la verifique.

- **Nombre correcto en todas partes:** «Queen SDA — Sistema de Automatización de Datos V2.0» · «Restaurante-bar La Reina».
- **Regla de oro:** cero datos de negocio inventados. Sin respaldo importado, todas las pantallas muestran «Sin datos todavía». El respaldo/IPV es la fuente de verdad y ninguna cifra se ajusta en silencio.

## Cómo correrla

```bash
npm install     # instala dependencias (React 19, Vite 6, TypeScript)
npm run dev     # servidor de desarrollo
npm run build   # comprobación de tipos (tsc) + construcción de producción en dist/
npm run preview # sirve la construcción de producción
npm run verify:import   # prueba del importador contra el respaldo real de referencia
```

## Puerta de calidad final (2026-10-25, local — sin desplegar)

Auditoría línea por línea contra `IGUALACION.md` y el código original, auditoría visual renderizada con el respaldo real sembrado (Chromium headless: 57 vistas — 4 anchos × 2 temas × pantallas principales y secciones de Más — con **cero desbordes horizontales y cero textos cortados** al cierre) y batería completa verde tras las correcciones. Defectos corregidos en esta puerta:

1. **La app no arrancaba** (defecto grave): en `App.tsx` los retornos tempranos de arranque/acceso quedaban ANTES de varios hooks; al llegar la sesión, React lanzaba «Rendered more hooks than during the previous render» y la pantalla quedaba en blanco. Los retornos se movieron tras todos los hooks y el arranque quedó probado en ejecución (local, con sesión admin y con sesión de lectura).

3. **Animaciones en segundo plano:** regla espejo del original — `visibilitychange` marca `data-queen-motion="paused"` y el CSS pausa todas las animaciones con la app oculta (antes solo se frenaba un reloj).
4. **Barra superior en teléfono:** el texto de marca desbordaba (documento +41 px a 390 y +71 px a 360 en todas las pantallas); el contenedor del texto ahora puede encoger y el subtítulo se elipsa, como en el original.
5. **Rejilla de Historial en teléfono:** columnas `minmax(0, 1fr)` — la etiqueta «Sin boletín» ya no empuja la rejilla fuera de la tarjeta.
6. **Lateral de escritorio como el original:** Principal = Cobrar, Gastos, Inicio, Queen (antes: Sistema en Principal) y Sistema en su sitio alfabético de «Más secciones»; la lateral ya no lleva la entrada «Más».
